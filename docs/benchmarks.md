# Benchmarks

This document lists the times to run `jekyll build` and `gojekyll build` on a
few different sites.

See the Benchmarks section of CONTRIBUTING.md for instructions on how to
run a benchmark.

Notes:

- SASS conversion is cached
- Pygments (for version gojkeyll <= 0.2.5) is cached.

## Generated benchmark site (2000 posts)

Generated by `go run ./benchmarks/generate` — 2000 posts, 20 pages, 10
includes, 4 layouts. Each post triggers ~10 template parses across 3 layout
levels and 6 includes.

MacBook Pro (13", M1, 2020), macOS Sequoia (15.5)
go1.25.6 darwin/arm64, ruby 3.4.7, jekyll 4.4.1

| Executable | Options         | Time               |
| ---------- | --------------- | ------------------ |
| gojekyll   | multi-threaded  | 5.644 s ±  0.503 s |
| gojekyll   | single-threaded | 14.528 s ± 0.579 s |
| jekyll     |                 | 14.853 s ± 2.597 s |

gojekyll (multi-threaded) is ~2.6× faster than Jekyll on this site.

## Software Design web site

Site source: <https://github.com/sd17spring/sd17spring.github.io>

116 markdown/HTML pages with SASS and multiple layouts.

MacBook Pro (13", M1, 2020), macOS Sequoia (15.5)
go1.25.6 darwin/arm64, ruby 3.4.7, jekyll 4.4.1

| Executable | Options         | Time              |
| ---------- | --------------- | ----------------- |
| gojekyll   | multi-threaded  | 653.8 ms ± 60.9 ms |
| gojekyll   | single-threaded | 1.243 s ± 0.093 s |
| jekyll     |                 | 2.486 s ± 0.236 s |

gojekyll (multi-threaded) is ~3.8× faster than Jekyll on this site.

### Software Design web site (historical, 2022)

MacBook Pro (13", M1, 2020), macOS Monterey (12.2)
gojekyll v0.2.5
go1.17.6 darwin/arm64

Notes:

- This site uses The GitHub metadata plugin. The results of that plugin are not
  cached. (See issue [#43](https://github.com/osteele/gojekyll/issues/43).)

| gojekyll   | multi-threaded; warm cache      | 1.118 s ±  0.110 s |

## Liquid v1.6.0 → v1.8.1 comparison

Measured by building gojekyll with both liquid versions (all other code identical).

| Site | liquid v1.6.0 | liquid v1.8.1 | Speedup |
| ---- | ------------- | ------------- | ------- |
| Generated (2000 posts) | 3.288 s ± 0.267 s | 3.010 s ± 0.153 s | ~9% |
| sd17spring (116 pages) | 430 ms ± 128 ms | 428 ms ± 113 ms | ~0% |

The liquid v1.8.1 release claims ~25% faster template rendering. The improvement
is diluted in end-to-end builds because file I/O dominates wall-clock time.
